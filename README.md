# Luna Memory Engine (LME)

Bio-inspired neuromorphic memory system with FPGA acceleration.

## Overview

LME bridges biological principles (STDP learning, natural forgetting) with hardware acceleration (PYNQ-Z2 FPGA).

## Architecture

- **Software Simulation**: Pure Python implementation for testing and development
- **Hardware Acceleration**: PYNQ-Z2 FPGA deployment for real-time inference

## Quick Start

```bash
cd lme/software
python yuehen_lme_daemon_v3.py
```
