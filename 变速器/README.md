# 变速器 (Transmission)

> **"桥"不是解题器，是变速器。**
> 它不承担任何"解题使命"——它只做一件事：把**大模型的内部状态（隐藏状态）**，翻译成**小模型能直接使用的形式**。
> 大引擎 → 变速器 → 小车轮。功率不减，只是换了齿比。

这是 Mostik「桥（Bridge）」的纯代码复现。按老吴的框架设计，由阿月 + 本地 Gemma4:31b 协作实现。

---

## 一句话结论

**变速器有效。** 注入大模型隐藏状态后，**冻结**的小模型在同一任务上 **0.542 → 1.000**。

---

## 机制（对齐 Mostik）

- sender（大模型）只"读"，产出**隐藏状态**，**不吐任何文字**
- 训练一座小**变速器**，把 sender 的隐藏状态映射成 receiver 的 soft-prefix
- receiver（小模型）负责全部生成；**两个模型参数完全冻结，只有变速器被训练**
- 通信带宽：从 **~17 bit/token 的文字"窥视孔"** → **连续潜空间**

## 方法学（本次踩坑与修正）

1. **测试设计**：必须用"对**小模型真难**"的任务 —— 用**文字处理**（带干扰的长文属性提取），而不是算术（0.5B 连三位数加法都满分，没有坡就没有桥的意义）。
2. **先证 gap 再谈桥**：立项门槛 = sender/receiver 差距显著（本任务 gap = +0.43）。
3. **`generate(inputs_embeds=...)` 在 Qwen2.5 + transformers 4.57 直接返回空** → 必须**手写贪心生成循环**（本项目 `gen_embeds`）。
4. Procrustes 对齐测量需 n ≫ d，否则 R² 虚高。

## 结果（v2，任务：4 干扰长文属性提取，n=120）

| 条件 | 准确率 |
|---|---|
| sender（上限） | 0.975 |
| **receiver 单独** | **0.542** |
| **题 + 变速器** | **1.000** |
| 变速器 only（不给题） | 0.000 → **非缺陷**：变速器不带解题使命 |

- **gap = +0.433**；**gap closed = 105.8%**
- 训练 loss → 0.000

## 几何发现（顺带印证）

Qwen2.5-1.5B ↔ Qwen2.5-0.5B 表征空间：**CKA 最高 0.9406（中层 12↔12）**，Procrustes **R²=0.983**
→ 支持 Mostik 的"**存在可预测的既有对齐基础**"，且**中层对齐最好**（=最优注入层线索）。
