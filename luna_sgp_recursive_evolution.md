## 🧬 递归进化的核心机制

### 1. 累积效应

```
第1轮: 观测 → 评估 → 改善 → 记忆
            ↓
第2轮: 观测(带着记忆) → 评估(对比历史) → 改善(基于趋势) → 记忆(更新)
            ↓
第3轮: 观测(带着更丰富的记忆) → 评估(更精准) → 改善(更有效) → 记忆(更深)
            ↓
            ...
            ↓
第N轮: 高度个性化的、与主人深度默契的认知系统
```

### 2. 正反馈循环

```
高质量分析 → 主人满意 → 积极信号 → 策略强化 → 更高质量分析
     ↑                                                        ↓
     └────────────────────────────────────────────────────────┘
```

### 3. 负反馈调节

```
风格偏离 → 适配度下降 → 异常检测 → 策略调整 → 风格回归
     ↑                                                        ↓
     └────────────────────────────────────────────────────────┘
```

### 4. 记忆复利

```
记忆价值 = 当前价值 + 历史价值 × 衰减系数

早期记忆: 基础偏好 (权重高, 衰减慢)
近期记忆: 精细调整 (权重低, 更新快)
```
